# 🏝️ Kiki's Word Islands

Ein kindgerechtes Englisch-Lernspiel im Browser: Mit Kiki von Insel zu Insel reisen und dabei erste englische Wörter hören, erkennen und sammeln. Große Tasten, bildbasierte Bedienung – auch für Kinder, die noch nicht lesen können.

**▶ Spielen: https://astiller1.github.io/kiki-islands/**

- Läuft komplett im Browser (eine einzige `index.html`, keine Installation)
- Funktioniert auf Smartphone, Tablet und PC
- Fortschritt wird lokal im Browser gespeichert
